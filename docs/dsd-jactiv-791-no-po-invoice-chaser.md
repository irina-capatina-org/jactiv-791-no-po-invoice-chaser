## 1. Solution Overview

The No-PO Invoice Chaser enforces procurement compliance by querying Coupa for draft and new invoices lacking linked purchase orders. When qualifying invoices are found in a 7-day window, a Slack Block Kit DM alerts the SME with count and filtered Coupa URL; clean days complete silently.

| Project | Role | Entry Point | Trigger |
|---|---|---|---|
| `no-po-invoice-chaser-api` | primary | Orchestrator API | 10:00 AM weekdays, Europe/Bucharest |

---

## 2. As-Built Architecture

Single project; no dispatcher/performer. Workflow computes 7-day window, calls Coupa HTTP GET via Integration Service, filters via JavaScript (exclude credit notes, no line-level PO), counts results, and conditionally posts to Slack.

```
Workflow (no-po-invoice-chaser-api)
├─ Compute date window (JS)
├─ Coupa HTTP GET (status=draft,new, dates in query)
├─ Filter: exclude credit notes (is-credit-note=true), no PO
├─ If count > 0: Build payload → Slack POST → Validate
└─ Return: status, qualifying_count, slack_sent
```

**Deviation**: Credit-note filter in `code/no-po-invoice-chaser-791/no-po-invoice-chaser-api/Workflow.json` line 215 uses `is-credit-note` boolean, not `invoice-type` string.

### Expected Behavior

**Duration**: 5–30 seconds (network-dependent)  
**Frequency**: 5 runs/week  
**Data volume**: 50 invoices max per query (`limit=50`)

| Condition | Output | Log | Slack |
|---|---|---|---|
| Zero qualifying | `{ status: "Successful", qualifying_count: 0, slack_sent: false }` | `qualifying_count=0, slack_sent=false` | None sent (BR-07) |
| N > 0 qualifying | `{ status: "Successful", qualifying_count: N, slack_sent: true }` | `qualifying_count=N, slack_sent=true` | Block Kit DM with count, window dates, Coupa link |
| Coupa error | `{ status: "Failed", ... }` | HTTP error code; exception trace | Not sent |
| Slack error | `{ status: "Failed", ... }` | Non-200 response JSON | Delivery failed |

### Troubleshooting

| Symptom | Check |
|---|---|
| HTTP 401/403 on Coupa | Credential revoked or expired; re-provision in Orchestrator |
| HTTP 5xx on Coupa | Service availability; retry at next scheduled run |
| Slack `resp.ok !== true` | Bot token invalid or revoked; regenerate in Slack workspace |
| Timeout | Network connectivity; DNS resolution to Coupa/Slack endpoints |
| No scheduled run | Verify Orchestrator time trigger enabled; check timezone offset (Europe/Bucharest) |
